Smart Enrollment Management System

An automated student lead and enrollment management system built using
Google Sheets and Google Apps Script. The project is designed to
organize incoming leads, track enrollment progress, manage course-wise
records, and monitor fee payments in one structured workbook.

📌 Project Overview
The system provides a central place to enter and manage student lead
information. When a counselor submits a lead, the record is
automatically transferred to the Main Datasheet, where it can be tracked
and organized by course.

It also includes KPI tracking, follow-up management, and EMI/payment
monitoring to make the enrollment workflow easier to manage.

✨ Key Features
- Structured Data Entry: A dedicated sheet for entering student
  and lead details.
- Automated Lead ID and Timestamp: Generates a unique Lead ID and
  records the entry date and time.
- Automated Submission: Transfers submitted records from the Data
  Entry sheet to the Main Datasheet.
- Course-wise Organization: Automatically displays records in the
  relevant course sheet.
- Dropdown-based Data Validation: Helps maintain consistent and
  standardized entries.
- Lead Status Tracking: Tracks whether leads are open or closed
  based on their enrollment status.
- Follow-up Management: Supports next follow-up date tracking.
- KPI Monitoring: Displays key metrics such as leads, conversions,
  revenue collected, and outstanding fees.
- EMI and Payment Tracking: Records fee payments and installment
  details, with visual reminders through conditional formatting.


  🛠️ Tools & Technologies
- Google Sheets
- Google Apps Script
- Spreadsheet formulas
- Data validation and dropdowns
- Conditional formatting

  
🔄 Workflow
1. A counselor enters student and lead details in the Data Entry
   sheet.
2. The system generates the Lead ID and entry timestamp.
3. The counselor submits the lead using the submission checkbox.
4. Apps Script transfers the record to the Main Datasheet.
5. The record appears in the relevant course-wise sheet.
6. KPIs, follow-up dates, lead status, and payment information can be
   monitored.
